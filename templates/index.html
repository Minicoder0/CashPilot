📖 How to Use & AI Usage Guide ▸

📁 Uploading Transactions

  1. Prepare a CSV file with columns: date, description, amount
  2. Click "Upload CSV" or drag & drop your file
  3. Transactions are auto-categorized and displayed instantly

🤖 AI Analysis

  • AI processing runs once per upload — results are cached
  • Re-requesting analysis on the same data returns cached results instantly
  • Only the first 50 transactions are sent to minimize token usage
  • This keeps API credit usage low and responses fast
